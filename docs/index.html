mikai-cli

У розробці

Неофіційний консольний клієнт для Mikai — каталогу аніме з українськими озвученнями та субтитрами. Пошук, розклад, новинки та ваші списки просто з терміналу.

mikai login
mikai search "frieren"
mikai list set mal:52991 --status watching --ep 5

Код: github.com/DeityLamb/mikai-cli

Проєкт не повʼязаний з командою Mikai. Працює через публічний API.
